# Post-Implementation Review Request

Review the implementation summary/diff and test results independently.

Primary question:

**What is wrong with this implementation even if all current tests pass?**

Check specifically for:

- deviations from the approved architecture,
- correctness gaps,
- hidden state/concurrency bugs,
- security/privacy regressions,
- missing failure handling,
- performance regressions,
- inadequate tests,
- backward-compatibility problems,
- migration/rollback hazards,
- code that is unnecessarily complex.

Return findings ordered by severity with concrete remediation steps.
